# 🖐️ VisionTouch AI

## AI-Based Multi-Mode Gesture Controlled Human Computer Interaction System

VisionTouch AI is a real-time touchless computer interaction system that allows users to control a PC using hand gestures through computer vision.

The system uses a webcam to detect hand movements and converts gestures into actions like mouse control, air drawing, zooming, and system commands.

---

## 🚀 Features

### 🖱️ Gesture Mouse Control
- Move cursor using hand movement
- Left click using gesture
- Right click gesture
- Smooth cursor tracking

### ✍️ Air Drawing Mode
- Draw in the air using finger movement
- Change pen colors
- Clear canvas using gesture
- Save drawings as images

### 🔍 Zoom Control
- Pinch gesture based zooming
- Zoom in and zoom out using hand distance

### 🔊 Voice Feedback
- Announces active modes
- Provides interaction feedback

### ⚡ Real-Time Interaction
- Live webcam processing
- Fast gesture recognition
- Smooth user experience
